# 外壳规则：提示词框架、时长、配乐判断、品牌念法

这里只管「格式和约束」——陈尚宇在 V07、P04 上实测确认过的。**框里填什么（光影、镜头、表演、衔接、声音、产品动作）按 `routing.md` 指向的外部原文写**，不在这里重复。

## 一、视频提示词框架（Seedance 2.5，全能参考，一段 2–7 个镜头）

格式来自 `knowledge/08-分镜衔接方法.md`（Solis 教程），不要改成英文 Shot 1/2 或散文式。

```
竖屏 9:16，写实电影感<类型>。<本段在影调弧线上的位置>。
图片1 是开场画面；图片2 是<角色A>，只负责<脸、发型、服装>（<本段有/没有哪件道具>）；图片3 是<角色B>；图片4 是<场景>，只负责<场景和左右朝向>，不继承图里的人物……
场景光：<场景级光源句>。

镜头1（<运镜>，<景别>，0–2s）：从图片1 的画面开始，<谁>在<哪>做<动作>，<起始状态> → <结束状态>；<本镜光向和看得见的后果>。
镜头2（<运镜>，<景别>，2–4s）：顺势接镜头1 的<动作>（继承：<…>），……结束在<结束态>，留给下一镜<接口>。
……

声音：<环境声床 / 动作声 / 音乐（先判断延续还是转折，见第三节）>。只有<谁>说话，只在镜头N。
画面里不出现任何文字和 logo（<例外>），<只写高风险负面项>。
```

框架里每一栏填什么、怎么写得好（先看 `quick-ref.md`，细节再查原文；题材配方查 `genre-playbooks.md`）：

| 栏 | 按哪份原文写 |
| --- | --- |
| 影调弧线、场景光、本镜光向 | DirectorSKILL `lighting-and-color.md` |
| 运镜、景别、机位高度、焦段 | DirectorSKILL `cinematic-language.md` |
| 素材职责、编排顺序、负面项 | seedance-tvc-director `seedance-2-5-prompting.md` |
| 继承 / 结束态 / 接口、段间衔接 | seedance-tvc-director `shot-handoffs-and-sound-bridges.md` |
| 动作和表演（只写看得见的动作） | 小逻 `小逻-剧本分镜脚本.md`；DirectorSKILL `blocking-and-staging.md` |
| 声音、对白 | DirectorSKILL `sound-and-dialogue.md` |
| 商品镜头 | seedance-tvc-director `product-actions.md` |

框架硬规则：
- 「图片 N」= 画布连线的先后顺序；视频节点作参考算「视频1」。`canvas_setup.py` 会打印核对。
- 每镜写起止状态，后一镜写「顺势接」。
- 台词保留英文原文写在引号里；一镜只一个人开口。
- 每段提示词能独立复制，不写「同上」。

## 二、时长约束

- **每个必须表现的情节点单独成一镜，至少 1 秒**；一镜最多 2 个动作。
  - 踩坑案例（P04）：把「狂奔 + 拽门 + 再跑 + 撞墙转身」塞进 2 秒，模型把门挪到死墙边、跳过中间那段；「吸血鬼一步步把女主逼进死墙」因为没写，整段没有。
- 写分镜先列「不演出来观众就看不懂」的情节点（追逐戏：退路被断 → 被逼后退 → 撞墙；温情戏：误会 → 发现真相 → 和解的那个动作；产品戏：问题出现 → 用上产品 → 问题解决的可见结果），逐个分配秒数，**不够就整段加长**（Seedance 2.5 官方版单段 4–30 秒）。总时长超了合同口径（25–30 秒，未确认），靠删次要镜头或出精简版解决，不压情节点。
- 段的切法：同一情绪、同一场景、要连续表演的放一段；换参考组合（如 A 段无腰包 / B 段有腰包）、悲剧 → 重来、剧情 → 商品写实时分段。30 秒片通常 3 段主体 + 补拍。
- 模型常把动作做得比写的晚（扑镜头写 1.5 秒，实际 2.8 秒才黑）：要落点的动作留 1 秒余量，后期截取。

## 三、配乐（和光色）逐段判断「延续」还是「转折」

写每段的「声音」前，对照上一段问：**这段的情绪和上一段一样吗？** 分镜里先给每段标好。项目里落到 `project.json` 视频 job 的 `"music"` 字段（start / continue / turn / none），`canvas_gen.py` 提交前强制检查：continue 没挂上一段视频、turn 挂了视频、没标，都会拒绝提交。

| 判断 | 例子 | 写法 | 参考挂法 |
| --- | --- | --- | --- |
| 延续 | 同一场景、同一情绪往下走：悲剧 A → 重来 B；温馨聚餐的前后两段；同一场追逐 | 「音乐延续视频1 的同一主题（曲风、乐器、BPM、调式），<张力变化>」；光沿用同一场景光句 | 挂上一段**选定**的视频作「视频1」 |
| 转折 | 情绪翻面：恐怖 → 商品展示；危机 → 获救；搞笑 → 温情；剧情 → 写实产品 | 提示词**开头**写全新的音乐（曲风、乐器、BPM、大调），再列出不要的上一段乐器和音效；光色整套换（光比、饱和度、色温） | **不挂**上一段视频（参考视频的音频分量远大于一句「转为大调」），要接画面只挂上一段尾帧图片 |

- 踩坑案例（P04）：C 段写了「音乐延续视频1 的同一主题，转为明亮俏皮的大调」并挂了 B 段视频 → 商品段还是恐怖管风琴。
- 转折点放在上一段的结束重音上（如胜利和弦），后期硬切。
- 音乐的具体写法（功能、BPM、乐器、入口由看得见的事件触发）按 DirectorSKILL `sound-and-dialogue.md`。

## 四、品牌露出与 CTA（2026-10-23 陈尚宇定）

- **剧情里提品牌只说品牌名，不说网址**：台词、字幕、道具上都不出现 naturestaurant.com / dot com。
- **结尾 CTA 不说品牌名**：改成引导关注主页，如 `"Follow for more."`、`"Hit follow — part two's on my page."`、`"Check my profile."`；画面字幕同理，不写品牌名和网址。
- **结尾品牌尾板最好不要**；一定要留，只闪一下（≤0.5 秒），不做停留的 logo 板、按钮、网址。
- P04 的 `"Grab a case at Nature-stawrant dot com."` 和带网址按钮的尾板是旧做法，新片不再照搬。

## 五、品牌名念法

- Seedance 不听括号里的读音提示：P04 CTA 前两批 6 个候选单独切词转写全是 "nature restaurant"，后面跟 ".com" 时更会拆成两个词。
- **台词原文直接写拼读**：如 `"Nature-stawrant? Never again."`（只念品牌名，不带网址，见第四节）；屏幕上的正确拼写交给字幕。
- 生成后 `review.py --brand natur` 把品牌词单独切出来转写，整句转写不可信；最终人耳确认，念法以客户确认为准。
- 品牌台词尽量 ≤6 个词、能看见嘴时用近景；超长拆两镜或改画外。
- 拼读不是稳定解（V02 2026-10-23）：同样写 "Nature-stawrant dot com" 3 条全错（nature star it / matristostorant），改成单独成句 "Nature-stawrant." + 停半拍 "Dot com." 再 1 条仍错。品牌词默认按画外处理：人物台词停在品牌词之前，品牌词放到官网录屏或尾板上用配音 / 字幕，不赌模型念对。

## 六、图片提示词框架（GPT-Image-2，英文）

顺序：景别和机位 → 角色身份描述（设定表里那句英文，逐字复制）→ 动作 → 光 → 构图留白 → 场景级风格尾句（逐字粘贴）→ 排除项。具体写法按 DirectorSKILL `keyframe-prompt-template.md`、`lighting-and-color.md`。

项目硬规则：
- 角色挂模特库三视图锁脸：`face, skin tone, age … must exactly match reference image 1. Do not lighten her skin`；只从服装参考里取服装，写明 `do not copy that person's face`。
- 要读的字不让 AI 生成；logo 用参考图并逐字母写拼写 N-a-t-u-r-e-s-t-a-u-r-a-n-t，出图后放大核对。
- 写清道具状态（这段有没有某件道具、是哪个版本，例：P04 腰包只在 B、C 段、A 段是廉价薄叉）；对比道具一眼能分清。
- 俯视角布局图不直接挂给首帧和视频（会带成俯拍），先用它出两个方向的场景图。
- 标了字的动线图只给人看，不连任何生成节点。
- 比例只用 1:1 / 9:16 / 16:9。
- 「只改某处」的编辑生图（如只加重妆容）也会重画胸口 logo，常拼错（V02 R3 两候选都坏：Naturesbiunty / Naturessurant）。编辑后必放大核对 logo；坏了用 ffmpeg 把编辑前那张的 logo 区域羽化贴回（同构图、缩放到同尺寸），不必重出。

## 七、真实性（项目规则）

- AI 剧情段（一眼假的夸张）不算产品宣称；商品段只表现真实外观和正常用法，不做 AI 压弯对比、「永不断」之类的性能画面和字幕。
- 规格、每箱数量、价格取自 `knowledge/06-官网商品目录.md` 或官网接口，价格注明取价日期、发布前重核；配送时效不写。
